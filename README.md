# 🟡 PAC-MATH

## 📘 Sobre o projeto  
O **PAC-MATH** é um mini jogo desenvolvido na disciplina de **Lógica de Programação**. Inspirado no clássico **PAC-MAN**, o objetivo do jogador é mover o personagem (PAC) para capturar o ícone que contém a resposta correta da equação exibida na tela.

O jogo une **diversão com raciocínio lógico e matemática**, sendo ideal para treinar operações básicas de forma dinâmica.

---

## 🎮 Como jogar  
- Uma equação aparece no topo da tela.  
- O jogador deve movimentar o PAC pelo mapa para escolher a resposta correta.  
- Se capturar a resposta errada, perde pontos.  
- Ao acertar, avança e uma nova equação é exibida.
